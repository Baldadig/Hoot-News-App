# Leeftijdsclassificatie

App Store Connect → je app → App-informatie → **Leeftijdsclassificatie** → Bewerk.

Hoot is een nieuwslezer: de inhoud komt van uitgevers en gaat soms over oorlog, misdaad en andere zware onderwerpen, net als de NOS of een krant. Voorstel voor de antwoorden:

| Vraag | Antwoord | Waarom |
|---|---|---|
| Geweld (cartoon, fantasie) | Geen | |
| Realistisch geweld | **Zelden/mild** | Nieuwsfoto's en koppen over oorlog en misdaad. |
| Langdurig expliciet geweld | Geen | |
| Seksuele inhoud of naaktheid | Geen | |
| Grof taalgebruik of ruwe humor | Geen | |
| Volwassen of suggestieve thema's | **Zelden/mild** | Nieuws over bijvoorbeeld rechtszaken. |
| Horror- of angstaanjagende thema's | Geen | |
| Medische of behandelingsinformatie | Geen | |
| Alcohol, tabak of drugs | **Zelden/mild** | Kan in het nieuws voorkomen. |
| Gokken (gesimuleerd) | Geen | |
| Wedstrijden, chat, door gebruikers gemaakte inhoud | Nee | |
| Ouderlijk toezicht, leeftijdscontrole | Nee | |
| **Onbeperkte webtoegang** | 🟡 **Jouw keuze: Nee (aanbevolen)** | Hoot opent alleen artikelen bij de uitgever, in de Safari-weergave. Die heeft geen adresbalk; je kunt niet zelf ergens naartoe surfen. Kies je **Ja**, dan wordt de leeftijd 18+. |

Verwachte uitkomst: **13+**, net als andere nieuws-apps met zulke antwoorden.
